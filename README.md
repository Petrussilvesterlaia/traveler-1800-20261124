One sentence that explains the modern internet to a time traveler from the year 1800, using only words a person from that year could know. It paints a single picture a traveler could hold in their head: a great library of light where every letter ever written waits together, and a whisper in the dark brings any one of them to hand in a breath — no list of features, no word coined after 1800.

## Run it

```sh
python3 main.py
```

The program validates the sentence (one line, exactly one sentence, 1–200 characters, pure ASCII), writes it to `/output/entry.txt`, reads it back, and verifies the round trip byte for byte.
